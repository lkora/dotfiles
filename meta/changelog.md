# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024-11-10

### Initial Release
- Sway Atomic OCI base image with Intel iGPU support
- Native packages: zsh, git, curl, wget, btop, htop, bat, fastfetch, fzf
- Flatpak apps: Librewolf, Krita, Obsidian, Mailspring, Telegram, Signal, VLC, OBS
- System-wide Nerdfont Mono + Catppuccin/Kangawa themes
- Moon wallpaper from Unsplash
- Dotfiles sync service with rollback capability
